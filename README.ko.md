# YtoTEXT (yt2text)

[English](README.md) · **한국어**

개인용 유튜브 → 텍스트 추출기. 로컬/홈서버에서 돌아가는 단일 파일 웹앱입니다.

유튜브 링크를 붙여넣으면 **자막**(빠름) 또는 **Whisper 받아쓰기**(자막 없는 영상도 가능)로
전체 텍스트를 뽑아서 문단/타임스탬프 형태로 보여주고, `.txt` / `.md` / `.srt`로 저장할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
python yt2text.py                # 옵션: --host, --port (기본 127.0.0.1:8765)
```

브라우저에서 → http://localhost:8765

## 우분투 노트북을 홈서버로 쓰기

```bash
git clone https://github.com/jaebeom/YtoTEXT.git
cd YtoTEXT
./install.sh    # venv + ffmpeg + GPU 라이브러리 + systemd 서비스 등록까지 한 번에
```

- 기본으로 `0.0.0.0:8765`에 바인딩됩니다 — 같은 네트워크/Tailscale에서 접속 가능.
  이 컴퓨터에서만 쓰려면 `HOST=127.0.0.1 ./install.sh`
- 서비스 관리: `systemctl status|restart|stop yt2text` · 로그: `journalctl -u yt2text -f`
- **뚜껑 닫아도 계속 돌게**: `/etc/systemd/logind.conf`에서 `HandleLidSwitch=ignore`로 바꾸고 재부팅
- **맥/폰에서 접속**: 같은 와이파이면 `http://<노트북IP>:8765` 바로 접속.
  밖에서도 쓰려면 노트북과 맥/폰에 [Tailscale](https://tailscale.com) 설치 후 같은 계정 로그인 → `http://<노트북이름>:8765`
- 코드 업데이트: `git pull && sudo systemctl restart yt2text` (GPU/의존성이 바뀌었으면 `./install.sh` 재실행)

## 기능

### 자막 모드 (빠름)
- `youtube-transcript-api`로 업로더/자동생성 자막을 바로 가져옴 (기본 선호: 한국어 → 영어)
- 결과 화면의 언어 칩을 클릭해 다른 자막 언어로 전환
- **봇 감지 회피**: 자막 요청은 한 번에 하나씩, 요청 사이 2~5초 랜덤 간격
- **차단 자동 복구**: 유튜브가 차단(429)하면 전체 요청을 쿨다운(90초부터, 반복 시 최대 15분까지 증가)하고
  화면에서 카운트다운 후 자동 재시도 (최대 5회) — 행별 [중지] / [차단 재시도 전체 중지]로 끊을 수도 있음

### Whisper 모드 (정확)
- `yt-dlp`로 오디오만 내려받아 `faster-whisper`로 받아쓰기 — 자막 없는 영상도 처리
- 모델 선택(large-v3-turbo 추천), 언어 자동 감지/고정, 진행률 표시, [취소] 버튼
- **GPU 자동 사용**: NVIDIA 드라이버가 있으면 CUDA로 받아쓰기. cuBLAS/cuDNN을 코드가 직접 로드하고,
  GPU가 어느 시점에 실패하든(모델 로딩·받아쓰기 도중 포함) CPU(int8)로 자동 전환해 작업을 끝까지 진행
- **긴 영상 안전 처리**: 1.5시간 이상은 1시간 단위 청크로 잘라 순차 받아쓰기 (메모리 폭주로 서버가 죽는 것 방지)
- 받아쓰기는 한 번에 한 편씩 순차 처리(순번 대기), 오디오 다운로드는 3개 병렬

### 배치 추출
- 링크 여러 줄을 한 번에 붙여넣기 (최대 50개), 행마다 개별 진행률 표시
- **중복 감지**: 이미 추출한 영상은 알림 행이 떠서 [열기] / [다시 추출] 선택. 기록이 지금 고른 것과 다른 방식이면 그 사실을 알려주고 버튼도 [caption으로 추출] / [whisper로 추출]로 바뀜 — 같은 영상이라도 자막본과 Whisper본은 따로 남음. 중복 감지는 지금 보고 있는 폴더가 아니라 **전체 기록**에서 찾기 때문에, 다른 폴더에 있거나 미분류로 남아 있는 영상도 걸림 — 안 보인다고 없는 셈 치면 Whisper를 통째로 다시 돌리게 되니까. 그래서 화면에 안 보이는데 "기록이 있어요"가 뜰 수 있는데, [열기]를 누르면 어느 폴더에 있든 열리고 카드의 🗂로 원하는 폴더에 넣으면 됨
- 배치 진행 중에 새 링크를 넣으면 큐를 리셋하지 않고 뒤에 이어붙임
- 자막 없는 영상은 실패 행에서 [Whisper로 추출] 버튼으로 바로 전환

### 결과 보기 · 내보내기
- 문단 보기 / 타임스탬프 보기 토글, 복사(HTTP·IP 접속에서도 동작), `.txt` / `.md` / `.srt` 다운로드
- **AI용 복사** — 제목·채널·영상 길이·URL에 영상 설명(더보기란)과 인기 댓글까지 머리말로 붙여서 복사. 제미나이/ChatGPT 등에 그대로 던지면 어떤 영상의 스크립트인지 맥락을 바로 잡아줌 (채널명·설명·댓글은 새로 추출하는 영상부터 저장됨)
- **인기 댓글** — 추출할 때 유튜브 인기순 상위 후보(최대 30개)를 훑어서 좋아요 많은 원댓글 5개를 같이 저장 (대댓글은 제외, 고정 댓글·채널 주인 댓글은 표시됨). 결과 화면 본문 위에 접힌 블록으로 보이고 AI용 복사에도 그대로 들어가서, 영상에서 무슨 말을 했는지뿐 아니라 사람들이 어떻게 반응했는지까지 넘길 수 있음. 댓글 요청은 응답 대기 10초 상한에 재시도도 최소로 걸어둬서, 못 가져오거나 느리면 그냥 댓글 없이 본문만 저장하고 넘어감
- `.md` 다운로드에도 채널명과 영상 설명이 함께 들어감
- **YouTube ↗** 바로가기 링크, 타임스탬프 클릭 시 유튜브 해당 지점으로 점프 — 영상↔텍스트 오가며 보기

### 히스토리
- 추출 결과를 로컬에 최대 300개 저장 — 썸네일 카드 그리드, 클릭해서 다시 열기, 개별 삭제
- **폴더** — 그리드 왼쪽 사이드바에서 테마별로 폴더를 만들고, 카드를 폴더로 끌어다 놓거나 카드의 🗂 버튼으로 골라서 정리. 폴더를 누르면 그 폴더만 보이고, 마지막에 보던 폴더는 새로고침해도 유지됨. 폴더는 추출 건이 아니라 영상에 붙어서, 같은 영상을 다른 방식(자막↔Whisper)으로 다시 뽑아도 넣어둔 폴더에 그대로 남음. 폴더를 열어둔 채로 새 영상을 뽑으면 그 폴더에 담겨서, 방금 뽑은 게 필터에 가려 안 보이는 일이 없음. 폴더를 지워도 영상은 안 지워지고 *미분류*로 돌아감
- **카드에서 다시 추출** — 카드의 ↻ 버튼을 누르면 처음 뽑았던 방식 그대로(자막이면 자막, Whisper면 같은 모델) 큐에 넣어 다시 추출하고, 그 히스토리 항목을 갱신함 (폴더는 그대로 유지)
- **정렬** — 최신순 / 오래된순, 제목순 / 제목 역순(한국어 정렬이라 한글이 먼저, 영문이 뒤), 영상 긴 순 / 짧은 순. 지금 보고 있는 폴더 안에서 적용되고 새로고침해도 유지됨
- 목록(`history.json`)과 전문(`results/`)을 분리 저장, 원자적 쓰기로 크래시에도 기록 보존
- 썸네일 로컬 백업 (영상이 지워져도 카드 유지)
- 제목을 못 가져온 항목(차단, 임베드 금지 영상 등)은 히스토리를 열 때 자동으로 다시 채움 — 싼 조회(oembed) 먼저, 안 되면 yt-dlp로 한 번 더. 복구는 일부러 얌전하게: 한 번에 20개까지, 시도마다 쉬고, 실패가 남으면 쿨다운(5분부터 최대 1시간)을 걸어서 히스토리를 다시 열어도 바로 재시도하지 않음

### 팀과 같이 쓰기 (선택)

- **계정 2개** — 주인(`YT2TEXT_OWNER_PW`)과 팀 공용(`YT2TEXT_TEAM_PW`). 환경변수로 비밀번호를 넣으면 로그인 화면이 켜지고, 안 넣으면 예전처럼 로그인 없이 동작
- **기록이 안 섞임** — 히스토리·폴더가 계정별로 완전히 분리됨. 같은 영상을 둘이 뽑아도 서로 덮어쓰지 않고, 남의 기록은 열지도 지우지도 못함. `user` 필드가 없는 기존 기록은 전부 주인 것
- **팀 기록은 30일 보관** — 팀 계정으로 뽑은 기록은 30일이 지나면 전문 파일까지 자동 삭제 (6시간마다 청소). 주인 기록은 안 지워짐
- **테일스케일에서만** — 로그인을 켜면 테일스케일 대역(`100.64.0.0/10`, `fd7a:115c:a1e0::/48`)과 로컬에서 온 요청만 받음. 같은 공유기 안에서도 열려면 `YT2TEXT_ALLOW_LAN=1`
- 로그인 시도는 IP당 5분에 10번 제한, 세션은 30일 유지 (서명 키를 `yt2text_data/secret.key`에 보관해서 재시작해도 안 풀림)

비밀번호는 저장소에 넣지 말고 systemd 드롭인으로 넣으세요:

```bash
sudo mkdir -p /etc/systemd/system/yt2text.service.d
sudo tee /etc/systemd/system/yt2text.service.d/auth.conf >/dev/null <<'EOF'
[Service]
Environment=YT2TEXT_OWNER_PW=주인비번
Environment=YT2TEXT_TEAM_PW=팀비번
EOF
sudo chmod 600 /etc/systemd/system/yt2text.service.d/auth.conf
sudo systemctl daemon-reload && sudo systemctl restart yt2text
```

`tailscale serve --bg 8765`로 HTTPS를 붙이면 주소가 `https://<머신>.<tailnet>.ts.net`이 되고, 복사 버튼이 쓰는 클립보드 API도 제대로 동작합니다.

### 안정성 · 보안
- Host 헤더 검사 + JSON Content-Type 강제 — 외부 사이트가 로컬 서버를 몰래 조작하는 것(CSRF/DNS 리바인딩) 방어
- 서버 재시작 시 진행 중이던 작업은 화면에서 실패 처리 (영원히 "진행 중"으로 남지 않음)
- 끝난 받아쓰기 작업은 10분 뒤 메모리에서 정리

## 참고

- 데이터는 전부 로컬 `yt2text_data/`에 저장됩니다 (목록 `history.json` · 폴더 `folders.json` · 전문 `results/` · 썸네일 `thumbs/` · 세션 키 `secret.key`) — git에는 올라가지 않음
- Whisper 모델은 최초 사용 시 자동 다운로드됩니다 (large 계열은 수 GB, 수 분 소요)
- 기본은 `127.0.0.1` 바인딩 + Host 헤더 검사로 외부/타 사이트 접근을 차단합니다 (`--host`로 바꾸면 검사 자동 해제)
- 유튜브 차단은 시간이 지나면 풀립니다 — 대량 배치는 몇 개씩 나눠서, 급한 건 Whisper 모드로
